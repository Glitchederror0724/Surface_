 # Surface Website

Official website for **Surface**, a Lua project currently under development.

## GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish.

## Customize

Search `https://github.com/` in `index.html` and replace it with your actual Surface repository URL.

You can also update the roadmap, changelog, description, and version whenever Surface gets new features.
